# Skilled
The repository for the Skilled mod. This mod is a WIP and changes may be frequent and major.

## About
The Skilled mod implements a class and skill tree system into Minecraft.

### Classes
- Ranger
- Warrior
- Paladin
- Rogue

## For users
1. Download the correct [Forge](https://files.minecraftforge.net/net/minecraftforge/forge/) version (1.20.1-47.4.0)
2. Download the JAR executable
3. Drag the JAR into the mods folder of your game
4. Launch the game

## For developers
### IntelliJ
1. Download the project and extract the ZIP file
2. Import the project into IntelliJ
3. Use 'gradlew genIntellijRuns' to generate run configurations
4. Run the 'RunClient' configuration to open the game
   
[Minecraft Development plugin for Intellij](https://plugins.jetbrains.com/plugin/8327-minecraft-development)
